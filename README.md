# Scientific Publication Reviews & Analytics

## Назначение проекта

Система предназначена для сбора и анализа пользовательских отзывов о научных публикациях из собственной базы данных и открытых интернет-площадок. Проект объединяет метаданные научных статей, отзывы пользователей и внешние обсуждения для последующего анализа тональности и визуализации результатов.

Система позволяет искать научные публикации по DOI или заголовку, получать метаданные из внешних научных API, сохранять отзывы, собирать обсуждения с Reddit и Hacker News, а также анализировать динамику и тональность отзывов.

## Используемый стек технологий

- **Язык разработки:** Python, JavaScript.
- **Backend:** FastAPI.
- **Frontend:** React, Vite.
- **База данных:** PostgreSQL (хранение публикаций, пользователей, отзывов и тегов).
- **Кэширование:** Redis (кэширование запросов к внешним API и аналитических эндпоинтов).
- **Внешние научные API:** OpenAlex, Semantic Scholar, arXiv, CrossRef, CORE.
- **Источники обсуждений:** Reddit API, Hacker News API.
- **Фоновые задачи:** Celery или ARQ.
- **Анализ тональности:** Transformers с моделью `nlptown/bert-base-multilingual-uncased-sentiment` или TextBlob.
- **Управление состоянием frontend:** Zustand или Redux Toolkit.
- **Визуализация данных:** Recharts или Apache ECharts.
- **Облако ключевых слов:** react-wordcloud или wordcloud2.js.
- **Тестирование:** Pytest, Vitest, React Testing Library, Cypress или Playwright.
- **Контейнеризация:** Docker, Docker Compose, Nginx.
- **CI/CD:** автоматизированный конвейер `lint → tests → build`.

## Архитектура

Система состоит из backend на FastAPI, frontend на React, базы данных PostgreSQL, кэша Redis и фонового воркера для сбора внешних обсуждений.

1. **Слой данных (Data Layer):** PostgreSQL хранит сведения о научных публикациях, пользователях, отзывах и тегах.

2. **API Layer (FastAPI):** предоставляет CRUD-эндпоинты для создания, редактирования и модерации отзывов, а также эндпоинты для поиска публикаций и получения аналитических данных.

3. **Сервис интеграции с научными API:** использует OpenAlex в качестве основного источника метаданных. Дополнительно поддерживаются Semantic Scholar, arXiv, CrossRef и CORE. Сервис выполняет поиск публикаций по DOI или заголовку и сохраняет полученные метаданные в PostgreSQL.

4. **Слой кэширования (Cache Layer):** Redis кэширует запросы к внешним API для снижения количества обращений и соблюдения ограничений частоты запросов.

5. **Фоновый воркер:** Celery или ARQ периодически ищет упоминания DOI и заголовков научных публикаций в Reddit и Hacker News. Собранные комментарии нормализуются, сохраняются в базе данных как внешние отзывы, а дубликаты обрабатываются.

6. **Слой анализа и аналитики:** выполняет анализ тональности отзывов и предоставляет данные о средней оценке, распределении тональности, наиболее активных авторах и динамике отзывов во времени.

7. **Frontend Layer (React):** предоставляет каталог публикаций с поиском и фильтрами, страницы научных статей с отзывами, форму добавления отзыва и отдельный дашборд аналитики.

8. **Слой визуализации:** отображает распределение тональности, динамику отзывов, наиболее обсуждаемые публикации и облако ключевых слов. На дашборде доступны фильтры по дате, авторам и тональности.

## Основные функциональные возможности

- Поиск научных публикаций по DOI и заголовку.
- Получение и сохранение метаданных публикаций из внешних научных API.
- Создание, редактирование и модерация пользовательских отзывов.
- Сбор внешних обсуждений с Reddit и Hacker News.
- Нормализация и сохранение внешних отзывов.
- Анализ тональности пользовательских отзывов.
- Расчёт средней оценки и распределения тональности.
- Определение наиболее активных авторов отзывов.
- Анализ динамики отзывов во времени.
- Визуализация аналитических данных на отдельной странице-дашборде.
- Фильтрация аналитики по дате, авторам и тональности.

## План разработки

1. **Инициализация проекта и базовая инфраструктура:** создание публичного монорепозитория с каталогами `backend/` и `frontend/`, подготовка README.md, настройка Docker Compose и CI/CD.
2. **Проектирование БД и базовый API FastAPI:** создание схемы PostgreSQL, реализация CRUD-эндпоинтов отзывов, настройка Pydantic-валидации и unit-тестов.
3. **Интеграция с внешними научными API:** подключение OpenAlex и дополнительных источников, реализация сервиса-агрегатора и настройка Redis-кэша.
4. **Сбор дополнительных обсуждений:** интеграция Reddit API и Hacker News API, реализация фонового воркера, нормализация и сохранение внешних отзывов.
5. **Анализ отзывов и базовая аналитика:** интеграция анализа тональности, реализация аналитических эндпоинтов и unit-тестов.
6. **Разработка React-фронтенда:** создание каталога публикаций, страниц статей с отзывами и формы добавления отзыва, настройка линтинга и тестирования.
7. **Создание дашбордов и визуализация аналитики:** реализация графиков, облака ключевых слов и фильтров аналитических данных.
8. **Контейнеризация и финализация CI/CD:** настройка production-контейнеров, профилей Docker Compose, end-to-end-тестирования, индексов PostgreSQL, пагинации и кэширования аналитических эндпоинтов.

## Тестирование и CI/CD

CI/CD-пайплайн включает этапы линтинга, тестирования и сборки для backend и frontend.

- **Backend:** unit-тесты API и аналитических функций с использованием Pytest.
- **Frontend:** базовые тесты компонентов с использованием Vitest и React Testing Library.
- **End-to-end:** проверка сценария поиска статьи, добавления отзыва и отображения данных на дашборде с помощью Cypress или Playwright.
